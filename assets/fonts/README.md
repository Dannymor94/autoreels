# Bundled fonts

Place `DejaVuSans-Bold.ttf` here for cross-platform Cyrillic title rendering in `make_covers.py`.

**Source**: https://dejavu-fonts.github.io — download `dejavu-fonts-ttf-*.tar.bz2`, extract `DejaVuSans-Bold.ttf`.  
**License**: DejaVu Fonts License (permissive, attribution not required in output).

The script falls back to system Arial (macOS/Windows) or system DejaVu (Linux `/usr/share/fonts/`) if this file is absent.
