# autoreels — Авто-Рилс

> CLI-инструмент: длинное горизонтальное talking-head видео → набор вертикальных
> **Reels 9:16** с выжженными субтитрами, заголовками и монтажом (два плана, перестановка,
> выделение слов, рамка по лицу). Два равноправных режима отбора: **автоматический**
> (`arl auto`: карта мыслей → автомонтаж или сценарист → проверки → рендер → посты → лист ревью)
> и **ручной** (человек или модель в любом чате размечает текстом).
> Облако работает с текстом, локаль рендерит (ffmpeg). Бесплатные API по умолчанию;
> платный Claude — только когда назван явно.

## Идея

Длинная лекция/эфир (один человек, статичная камера) нарезается на короткие вертикальные
клипы. LLM размечает мысли источника и предлагает строки монтажа (или человек пишет
разметку сам); каждое предложение каждой строки проверяет код. Итог — черновик, который
владелец смотрит на листе ревью. Границы, монтаж, проверки и рендер ставит
детерминированный код. Время слов и пауз берётся из **карты речи по звуку**, а не из
таймкодов Whisper.

### Несущая граница: ОБЛАКО / ЛОКАЛЬ

**Видео между тирами не передаётся.** Облако работает только с текстом, тяжёлое — локально.

| | ОБЛАКО (API) | ЛОКАЛЬ (железо) |
|---|---|---|
| Делает | транскрипция, карта мыслей, строки монтажа, посты | проверки, нарезка, кроп по лицу, субтитры, рендер |
| Инструменты | Groq (Whisper + LLM), OpenRouter; Claude — по имени; gamebox (whisper.cpp, локальная LLM) | ffmpeg, OpenCV (YuNet) |
| Стоимость | бесплатный тариф (Claude — платно, явно) | бесплатно |
| На выходе | **JSON-манифест** (план) | mp4-рилсы |

Это выражено в коде физически: [`src/autoreels/cloud/`](src/autoreels/cloud/) ⟂
[`src/autoreels/local/`](src/autoreels/local/). Мост — манифест ([`core/models.py`](src/autoreels/core/models.py)).

## Конвейер

```
видео ──► extract_audio ──► transcribe ──► compress ──► select (R0) ──► манифест
         (ffmpeg -vn)      (Whisper,      (sentence-    (LLM ранжирует,
                            word-level)    level проекция) код решает)
                                                              │
                              манифест ──► cut + crop 9:16 ──► burn ASS субтитры ──► mp4
                                           (R1)                (R3)
```

Основной путь для новых источников (`arl auto`, M63):

```
транскрипт ─► tx-check ─► map (мысли) ─► autocut | --scenario ─► черновик reviews/<stem>_auto_*.txt
                                                                     │  (та же грамматика, что ручная разметка)
          лист ревью ◄── describe (посты) ◄── render ◄── --apply (проверки каждого клипа)
```

**Выпуск (после `arl auto` и просмотра листов ревью; гейт `<g>`, все команды из корня проекта):**

1. Посты, которых нет: `arl describe <ист> --gate <g> --reels r03,r07 --force`.
2. Выгрузка для crosspost: `arl crosspost <ист> --gate <g> --reels <все клипы гейта>` → `export/crosspost/<ист>/`, `<ист>_<g>.csv`.
3. Сетка по смыслу: `python tools/grid.py <g> --from <гейт прежней сетки>` → `export/crosspost/schedule.csv`, `grid.csv` (Дата; Время; Что; Куда; Заголовок; Текст поста), `plan_by_date.csv`. Новые клипы встают в конец — переставить в `schedule.csv` по смыслу, затем `python tools/grid.py <g> --from <g>`.
4. Общий каталог: `python tools/publish_dir.py <g> --do` → `export/publish/NNN_rXX_<источник>.mp4` + пост и обложка. После каждой пересборки сетки — снова.
5. Проверка скачков кадра: `python tools/measure_shots.py reviews/*_<g>.review.json` (вспышек должно быть 0).

Публикует владелец (crosspost или руками); `arl` ничего не публикует.

**Переключатели `arl auto`** (M153; значения по умолчанию — в `config/r0.yaml`, раздел `autocut:`, и `config/render.yaml`):

| что | как переключить |
|---|---|
| кто пишет ролики: сценарист (платный Claude) или автомонтаж (бесплатно) | `autocut.auto_mode`; на один прогон `arl auto … --mode scenario \| autocut`. Сценарист не ответил (нет ключа, ошибка API) — источник идёт автомонтажом, итог это называет |
| модель сценариста | `autocut.scenario_llm`; на прогон `--scenario-llm haiku \| sonnet` |
| тон сценариста | `autocut.scenario_tone`; на прогон отдельно: `arl autocut <ист> --scenario --llm sonnet --ac scenario_tone=фановый` |
| модель карты, судей и постов | `--llm auto \| cloud \| local \| none \| sonnet`; до `autocut.paid_until` `auto` = `autocut.paid_llm` (M157: промо-кредиты), после — бесплатные модели, а сценарист только с `--mode scenario` |
| реплики ведущего (интервью) | `autocut.interviewer: on \| off`; на прогон `arl auto … --interviewer on \| off`; карта говорящих — `arl speakers <ист>` (M165) |
| рендер на gamebox (видеокарта, H.264) | `arl render --manifest … --gate … --remote`, `arl auto … --remote` (M161; `config/render.yaml remote:`) |
| черновики прогона под своими именами | `--tag <имя>` → `<ист>_auto_<имя>.txt`, `<ист>_auto_all_<имя>.txt`, `<ист>_<имя>.review.json`: черновики прежнего листа и его файл решений не трогаются |
| расшифровка нового видео | `--tx groq \| local` |
| рендер, музыка, папка | `--no-render`, `--music <трек>`, `--gate <имя>` |
| короткие планы (скачки кадра) | `short_shot_sec` в `config/r0.yaml` (0 — выкл.): план короче — предупреждение, автоматический клип выбрасывает его фразы; клип разметки в `arl auto` убирается (M173, M174, M177) |
| повторы между разметкой и сборками в `arl auto` | `autocut.combined_overlap_max` (1 — выкл.): клип разметки, чьи секунды больше этой доли звучат в уже оставленном клипе, убирается (M177) |
| крючок из части фразы; строгое начало ролика | `autocut.hook_clauses` (холодный старт — кусок длинной фразы между паузами, `h:B.N@i-j`); `autocut.start_strict` (ролик не начинается со ссылки назад или обращения к собеседнику: начало раньше на фразу-две, иначе ролика нет) (M182) |
| крючок клипам разметки | `autocut.label_hooks` — клип разметки в `arl auto` получает крючок из своей второй половины (M183) |
| голос поста | `post.voice: author \| reader` — от «я» (сам автор) или о ролике (M173) |
| остальные приёмы клипа (пред-ролл, громкость, концовки, карта речи…) | флаги `config/render.yaml` и `config/r0.yaml`, каждый с комментарием; выключенный флаг = прежний выход |

Правила самого клипа — [`docs/REEL_SPEC.md`](docs/REEL_SPEC.md).

**Determinism-first:** LLM только предлагает и ранжирует кандидатов; финальные границы,
отбор, чек-флаги (`too_long`/`too_short`/…) ставит код. Пустой результат — валиден.

**Каждый клип проверяется автоматически:** кончается на законченном предложении, слова на
экране = слова в звуке, после последнего слова нет чужой речи, последнее слово не
приглушено, файл цел и кадр не зависает.

## Требования

- **Python 3.11+** (закреплён в `.python-version` = 3.13; системный macOS Python 3.9 не подойдёт).
- **ffmpeg** в `PATH`, **собранный с libass** (фильтр `ass` для субтитров). Обычная
  Homebrew-формула собрана без libass — на macOS ставить из тапа `homebrew-ffmpeg/ffmpeg`.
  Проверка: `ffmpeg -filters | grep -w ass`. Mac: кодек `hevc_videotoolbox`; Windows AMD: `hevc_amf`.
- **`GROQ_API_KEY`** в окружении (см. [`.env.example`](.env.example)) — Whisper + LLM. `OPENROUTER_API_KEY` — запасной провайдер.
  `ANTHROPIC_API_KEY` — только для `--llm haiku|sonnet` (сценарист, посты), платно.
- **Детектор лиц YuNet** для рамки ролика — файл `data/models/…onnx`, команда скачивания — в [`config/render.yaml`](config/render.yaml) у `face_model`. Без файла — каскад Haar (хуже).

## Запуск одной командой

```bash
source start.sh        # (или коротко: . start.sh)
```

Поднимает всё окружение и открывает меню: определяет корень проекта, активирует
`.venv` (Mac `bin/` / Windows Git Bash `Scripts/`), при первом запуске **сам** создаёт
venv и ставит `autoreels`, подключает короткие команды `arl`, предупреждает если в `.env`
нет `GROQ_API_KEY`, показывает статус и запускает меню.

> Запускать через **`source`** (не `./start.sh`), чтобы venv и команды `arl` остались
> в текущем shell после выхода из меню. Двойным кликом: **`start.command`** (macOS) /
> **`start.bat`** (Windows) — откроют терминал с готовым окружением.

Удобный алиас (один раз в `~/.zshrc` / `~/.bashrc`):
```bash
alias start='source /путь/к/autoreels/start.sh'
```

> Команда называется **`arl`**, а не `ar`: `ar` — системный Unix-архиватор,
> и `ar run …` попадал бы в него с невнятной ошибкой. `install-aliases` делает
> `arl` доступной в любом новом терминале (сама активирует venv, работает из любой папки).

`arl` без аргумента открывает **меню**: в шапке — состояние проекта,
▶ помечает рекомендуемый шаг, пункты запускаются цифрой. `arl run <путь|URL>`
(пункт 2 меню) принимает файл **вне `inputs/`** — он обрабатывается **на месте**
(не копируется в `inputs/` и не архивируется: крупные файлы 14 ГБ не дублируем; файл
остаётся там, где лежит) — **или** ссылку:

- **YouTube и пр.** — yt-dlp в `inputs/` (1080p max, `--no-playlist`);
  нужен `pip install 'autoreels[url]'`.
- **Яндекс.Диск** (`disk.yandex.ru/i/…`, `yadi.sk`) — public API + curl,
  без доп. пакетов. Только файлы (`/i/`), не папки (`/d/`). Большие файлы
  Я.Диск троттлит — скачивание может быть долгим; при обрыве докачивается
  (`curl -C -`) со свежим временным URL.

### Транскрибация для контента (`arl t`)

`autoreels transcribe <видео|аудио|url>` — отдельная выжимка текста из речи
(посты/статьи из сказанного), тот же приём источника, что и `run`:

```bash
arl t inputs/лекция.mp4                 # → transcripts/лекция.txt
arl t podcast.mp3 --format srt          # субтитры с таймкодами
arl t https://youtu.be/XXXX --format json
```

- `text` (дефолт) — **связный** текст, разбитый на **абзацы по смысловым паузам**,
  **без таймкодов** (удобно перерабатывать в контент);
- `srt`/`vtt` — субтитры с таймкодами; `json` — сырой word-level `{word,t0,t1}`.

Длинное видео чанкится автоматически. Результат — в `transcripts/`.

**`run` тоже сохраняет транскрипт** попутно: после Whisper (до R0) кладёт
`transcripts/<имя>.txt` — отдельный `transcribe` на то же видео не нужен.
Транскрипт кэшируется по хэшу аудио (`data/cache/`), кэш общий для `run` и
`transcribe`: повторный прогон не гоняет Whisper заново.

> **`transcripts/` — локальная папка, не в git.** Транскрипты воспроизводимы из
> `data/cache/` (ключ = хэш аудио + параметры транскрибации). Машина рендера их
> не читает — ей нужен только манифест.

**Энкодер и путь к ffmpeg** — не флаги. Общие дефолты в [`config/render.yaml`](config/render.yaml)
(в git), **машинные** настройки — в `config/render.local.yaml` (в `.gitignore`, накладывается
поверх через deep-merge), чтобы путь ffmpeg на Windows не уезжал на Mac:

```bash
cp config/render.local.yaml.example config/render.local.yaml   # один раз на машине
```
```yaml
# config/render.local.yaml — только машинные отличия
ffmpeg: D:\ffmpeg\bin\ffmpeg.exe   # Windows: ffmpeg вне PATH
encoder:
  codec: h264_amf                  # Windows AMD; h264_nvenc NVIDIA; libx264 CPU
```

Тогда `python -m autoreels render` (без флагов) работает как есть. Альтернатива без файла —
env `RENDER_FFMPEG` / `RENDER_ENCODER`. Приоритет: флаг > env > `render.local.yaml` > `render.yaml`.

Алиасы обновляются через `git pull` — правишь [`aliases.sh`](aliases.sh), коммитишь.
