Retain request, attempt fence, worker identity, cancellation intent and active output reservation; reject stale finish/renew and duplicate reservations. Already reconciled, queued and terminal jobs remain unchanged. Current source/config drift does not prevent quarantine. Existing files are never deleted or accepted by recovery. No new public endpoint, launcher, live queue, real media, remote execution or automatic retry.

The test demonstrates controller death and crash-safe ledger quarantine, NOT live orphan-child termination or complete OS process reconciliation. A free controller lock is not proof of orphan exit. Reconciliation/retry remains disabled until trusted proof of process exit and output verification.
