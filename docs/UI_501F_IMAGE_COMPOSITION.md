# UI-501F — first synthetic still-image composition

MEDIUM, opt-in and trusted synthetic-only. Extend the existing graphic layer to allow exactly one solid color or a typed ImageAsset. Absent image preserves legacy serialization and fingerprints. Reuse final-frame coordinates and output time; fit the still in its rectangle preserving aspect ratio with black letterboxing, under subtitles and over the seam dip. Use the existing FFmpeg graph, a fixed private temporary basename, byte hash check and explicit PNG decode. No client-supplied path, filter, network, upload, download, production activation or owner media. Local resolver validates bytes before reuse and after render; staged request binds the exact asset. Synthetic actual renderer regression uses two contrasting halves of a PNG, verifies decoded colors only during the interval and checks unchanged speech/music and duration. No extra dependencies. The editor still offers solid presets only; user image selection and saved-export staging are separate. Exact-head CI required.
