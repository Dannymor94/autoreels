# UI-501K — ordered solid graphic layers

MEDIUM opt-in: the existing single graphic_layer remains byte-compatible; the alternative graphic_layers stack contains one to four validated solid rectangles in back-to-front order. The two representations are mutually exclusive. All layers share the existing final-frame output clock and hard-cut compatibility guard; the renderer applies them in order before subtitles, with no external assets, arbitrary filters or new dependencies. Cache fingerprint includes exact order and timing. Existing FFmpeg test adds overlapping white/blue rectangles, checks decoded pixel order and disappearance, and verifies unchanged soundtrack and A/V duration. Still/video layers remain single-layer only; mixed media stacks and UI controls are separate. No real media, deployment or new HTTP routes. Exact-head CI required.
