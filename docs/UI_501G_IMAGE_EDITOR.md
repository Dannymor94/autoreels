# UI-501G — synthetic image selection and saved export

Reuse the existing graphic selection code and immutable revision store; add one fixed bundled image option. The source PNG is an original generated two-color test pattern (not user media), with a single typed asset descriptor and exact SHA-256. Preview uses the same fixed image and final-frame rectangle with aspect-ratio fit. Existing trusted offline saved-export adapter verifies and stages those exact bytes; no upload, arbitrary filename, download, external network or real-project activation. Browser smoke selects the image and reloads; existing end-to-end saved-revision export checks both colors in decoded MP4 and soundtrack. Other solid presets and undo/redo remain available; actual user asset library and free positioning remain separate. Dependent on UI-501F; mandatory exact-head CI.
