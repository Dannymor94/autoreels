# UI-502C — synchronized synthetic soundtrack preview

MEDIUM, browser-only synthetic slice. Existing persisted soundtrack remains canonical. Preview follows output-time position (including reordered/retimed source windows), loops the exact bundled audio asset at native rate, applies approximate volume/fade, stops on pause, seek, edit and unmount. Audible play is initiated directly in a user gesture; independent audition remains available. No separate audio engine, server changes or media transfer. Browser volume support and playback policy vary; failures are visible and do not alter saved settings. The demo has no voice, so ducking and final normalization remain authoritative FFmpeg-only. This is not sample-accurate mixing or physical mobile-device acceptance. Existing browser smoke covers one play/pause sequence and persisted selection. No new dependencies or deployment.
