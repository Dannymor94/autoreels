# PLAN-M1.7 — «Смонтировано, а не нарезано»

Отбор доведён (4% брака на ручном пути). Ролик читался как выдержка из записи: один кроп на весь клип, неподвижная камера, сидящий спикер. M1.7 добавляет минимальный набор режиссёрских решений, которые зритель считывает как монтаж. Без трекинга, без детекции, без новых входных данных от пользователя.

Статус шага меняет только человек после просмотра. Агент пишет «IMPLEMENTED, GATE PENDING».

## Принципы

- **Детерминированно.** Каждое визуальное решение выводится из калибровки и строки разметки.
- **Флаг на каждый шаг.** В коде выключен по умолчанию, включается в `config/render.yaml`. С выключенным флагом рендер идентичен прежнему: побайтово, если кодек детерминирован, иначе совпадают argv ffmpeg и фильтрграф.
- **Длительность неприкосновенна, новых швов нет.** `hevc_videotoolbox` добавляет кадр на шов; переключения внутри окна делаются по времени, без разреза окна.
- **Ручной путь только форматирует.** Оформление (планы, ключевые слова, хвост) работает на обоих путях; перестановка — решение по содержанию, только ручной путь.
- **Один шаг за раз, гейт после каждого:** `--apply` → рендер в `reels-out/<stem>/_gate/<шаг>/` → просмотр → вердикт одной строкой на клип.

## Шаг 1 — два плана ✅

Флаг `two_shot`.

- **Общий** — калиброванный кроп. **Крупный** — уже в `close_shot_scale` раз, горизонтальный центр общего, вертикаль по `close_shot_anchor_y` (точка на этой доле высоты общего плана остаётся на той же доле крупного — голову не выдавливает вверх). Чётные размеры, точные пропорции, всегда внутри кадра; масштаб меньше 1 приводится к 1 с предупреждением.
- Крупный на холодном старте `h:` и на `c:`; без них — один общий план, как раньше.
- На шве со сменой плана — **жёсткая склейка** (наплыв двух кропов одного дубля двоит); на остальных швах — прежний `video_xfade_sec`. Шов считается сменой плана и когда интервал крупного плана касается границы окна.
- Смена внутри окна — две ветки кроп+скейл и `overlay` с `enable='between(t,a,b)'`, окно не режется. Интервалы выровнены по сетке кадров, допуск касания — полкадра реального fps.

**Решения гейта:** масштаб 1.25 оставлен (источник 4K, реальный апскейл крупного ~1.11 — запас по резкости до ~1.4); жёсткая склейка вместо наплыва.

## Шаг 1b — авторитм планов ✅

Флаг `two_shot_auto` (требует `two_shot`). Форматирующая стадия, оба пути отбора.

- Ручные `h:`/`c:` важнее; автоматика заполняет остальное.
- Смена плана на каждом шве: `x:`, склейки блоков, вырезы филлеров.
- **Предел длины плана** `two_shot_max_shot_sec` (оба плана, симметрично): длинный план делится итеративно в точке, ближайшей к пределу, по уровням отката — пауза → граница предложения → граница после запятой. Нет кандидата — причина пишется в отчёт.
- **Минимум длины** `two_shot_min_sec` проверяется по итоговому списку переключений, откуда бы они ни пришли.

**Урок:** паузы по Whisper на этой лекции нулевые и отрицательные — правило «ждать паузу» не срабатывало вовсе; граница предложения без паузы — нормальное место склейки.

## Шаг 1c — перестановка тактами ✅

Синтаксис — `docs/task-scripted-clips.md`:

```
43 85 | s:1 | e:6 | t: Страх — это сигнал
> 5
> 1-3
> 6
```

- Строки `>` задают предложения в порядке воспроизведения; `s:`/`e:` — отрезок, внутри которого нумеруются такты. Предложение может повторяться (предупреждение).
- Стык **несоседних** предложений: зазор `beat_gap_sec` и обязательная смена плана (минимум длины на неё не распространяется — иначе джамп-кат). **Соседние** предложения сохраняют исходный тайминг.
- Такт не содержит звука другого такта: конец такта — по слышимому концу своего последнего слова и строго до начала следующего предложения источника (таймкоды Whisper перекрываются).
- `c:`/`k:` следуют за предложением, куда бы оно ни попало. Хвост — после последнего сыгранного такта.
- Предупреждения: такт начинается со связки или местоимения, отсылающего назад («и», «это», «поэтому», «потому что»…); заканчивается на связке или без терминального знака.
- Только ручной путь.

**Наблюдение гейта:** короткий клип с ударной фразой первой «увлекает»; длина — вопрос разметки, не кода.

## Шаг 2 — ключевые слова в субтитрах (ждёт просмотра)

Флаг `subtitle_keywords`. Поле `k:4=страх,сигнал;7=тело`.

- Меняется только размеченное слово (стиль `Keyword` из конфига); остальной текст, разбивка строк и тайминг — как были. Пословного появления и приглушения нет — это отдельный шаг, если окажется слабо.
- Совпадение по нормализованной форме (регистр, ё→е, без пунктуации); `страх*` — по префиксу. Пунктуация остаётся вне выделения.
- Промах, исключённое предложение, слово, съеденное вычисткой, `k:` при выключенном флаге — предупреждение, не ошибка.

**Проверить при просмотре:** слово появляется вместе со строкой (сброс стиля не съел затухание), цвет читается на кадре, в начале клипа не спорит с плашкой заголовка; выделять ли повтор слова в одном предложении («страх порождает страх»).

## B — финальный пакет концовки (задача собрана)

Цель — конец клипа читается как намеренный, даже если мысль чуть открыта. Каждый приём под своим флагом, по умолчанию выключен; сравнение вариантов на одних и тех же клипах в `_gate/ending/<вариант>/`.

1. **«Кнопка»** — самое сильное законченное предложение последним (строка в промпте выгрузки, перестановка `>`).
2. **Последнее предложение крупным планом** (`end_close_last`).
3. **Стоп-кадр** на слышимом конце последнего слова, держится до конца клипа, затем чёрное (`end_freeze`).
4. **Фирменный звук** после последнего слова (`end_sting_path`; до появления своего файла — сгенерированная заглушка).
5. **Тихая подложка** с приглушением под голос (`music_bed_path`).
6. **Плашка «Продолжение — в полной лекции →»** только для клипов с `open_thought` (`open_thought_card`).
7. **Концовка-петля** (`ending_style: loop`) — без стоп-кадра, чёрного, звука и плашки, для клипов с холодным стартом.

Звук и плашка добавляют время — ожидаемая длительность их учитывает; стоп-кадр, крупный план и подложка длительность не меняют.

## Монтажный проход (задача собрана)

Приёмы M1.7 включаются разметкой (`k:`, `>`, `c:`, `h:`), а разметка источников написана до их появления — в готовых клипах приёмов почти нет. Выгрузка уже отобранных клипов (`arl blocks <манифест> --montage`) с пронумерованными предложениями, паузами и промптом: модель в чате предлагает для каждого клипа `k:`/`>`/`c:`/`h:`, владелец правит, ответ сливается в файл разметки (поля `s:`/`e:`/`x:`/`t:`/`d:` не трогаются), дальше детерминированно.

## Отложено

- **Остаток сценарной разметки** — `zoom:` (наплыв), `hold:` (пауза перед ударной репликой), `emph` как такт (заменит `c:`). После M1.8: опираются на паузы, а паузы по Whisper ненадёжны.
