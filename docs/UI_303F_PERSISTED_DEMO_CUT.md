Fixed fixture mismatch after planner changes fails closed, no silent migration. UI keeps confirmed cut across reload and shows selection history; save and restore use exact CAS, retry or refresh on conflict. No owner media, real speech, real project writes, deployment, full undo/redo for arbitrary audio edits, or new dependency. Limit 100 demo revisions. Production shared authority and HIGH review remain separate.
