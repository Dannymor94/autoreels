# UI-402B — synthetic sentence permutation (planner slice)

Read-only `reorder_sentences` uses the existing manual audio planner, `Reel.reordered` and source-time segments. It accepts only a permutation of the exact current reproducible simple body; no new timeline engine, no live manifest changes. The speech-map validation shared with removal is retained. The candidate must preserve the exact audible word order, coverage and subtitle order. Existing cuts remain excluded. Reordering again and restoration are covered with a fixed synthetic three-sentence fixture. Complex plans and incomplete speech evidence fail closed. No UI, API, revision-store migration, real media, mobile renderer or FFmpeg acceptance is included in this slice. These are subsequent gates, not completed features.
