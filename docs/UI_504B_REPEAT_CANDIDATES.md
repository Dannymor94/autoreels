# UI-504B — conservative text-only repeated-take suggestions

First isolated LOW slice of whole-video cleanup. Accept existing sentence units; return both 1-based transcript references, the evidence category, and matched token count in stable source order. No deletion, proposed cut interval, automatic preference for the last take, semantic classification, media read, API, UI, Manifest write, or production activation. Exact normalized text and a shorter apparently unfinished prefix are candidate hints, not proof of a recording mistake. Negation is retained; completed-prefix extensions are not flagged as restarts. Fixed provisional locality: at most two preceding sentence units and at least four tokens. These are engineering defaults, not measured quality thresholds. Real temporal proximity, revision binding, audible coverage and any subsequent edit must use the existing speech-aware planner and separate owner-approved quality evaluation. Focused synthetic tests live with existing read-only sentence operations in the current UI CI suite; no extra workflow or independent QA for this pure slice. No provider calls or dependencies.
