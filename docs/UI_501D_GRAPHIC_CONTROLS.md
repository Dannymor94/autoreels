# UI-501D — persistent synthetic graphic controls

MEDIUM: four bounded rectangle presets expose position, color and half-open output-time intervals using the existing typed GraphicLayer. The server alone generates exact candidate Manifest bytes. The immutable selection key extends with -6; legacy selection keys, serialized operations and plans remain unchanged when absent. Existing CAS, undo/redo and saved-cut export are reused. Only the active underlying montage's graphic variants are enumerated, avoiding a Cartesian product; other interactive edits require explicitly removing the layer first (restore/undo remain available). Browser preview shows the same final-frame percentage geometry and output-time interval; approximate playback only. Targeted API invalid-selection/reload/undo/redo checks, browser smoke and existing actual saved revision export with pixel assertion. No arbitrary geometry input, image/video assets, multiple layers, real media, new dependency or production deployment. Exact-head mandatory CI.
