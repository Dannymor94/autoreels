# UI-602A — deterministic review of grounded insert suggestions

MEDIUM, read-only synthetic pilot. A future contextual model may rank pairs of transcript sentence IDs and registered visual asset SHA-256 values; it never proposes timings or paths. Exact canonical Manifest and transcript review digests; trusted caller binds speech evidence and catalog to the source. Placement maps complete audible sentence spans into uniquely retained output windows (including reordered/rate-adjusted windows), clamps duration to the asset and policy, respects existing manual layers, rejects ambiguous, missing, duplicate and overlapping suggestions. Pilot defaults: 0.3–1.5 s, minimum 1 s separation, full-frame, maximum four visual layers including one still/one video. Configurable policy; no claim of semantic relevance. Returned proposals require human confirmation and exact revision commit in a later integration. No LLM call, actual user media, download, application, renderer launch or production activation. Focused offline test reuses existing speech-map and manifest contract. Exact-head CI.
