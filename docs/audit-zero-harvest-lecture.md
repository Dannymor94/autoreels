## 3. ЧТО ВОЗВРАЩАЕТ МОДЕЛЬ

**Сырые ответы не кэшируются.** Файл `data/runs/r0_live_response.json`
содержит ответ от другого источника (хуки о «внутреннем ребенке», временны́е
метки 284–651 с совпадают с `2046ef16...transcript.json`, не с
`6f020f61`-лекцией). Для zero-harvest сохранённых ответов нет.

**«Найдено 0 моментов»** — это значение `len(all_reels)` в `select.py:477`
*после* пер-чанкового отсева (score < 65 и duration < 18 с).
Возможны два сценария:

| Сценарий | Признак |
|----------|---------|
| Модель возвращает `{"segments": []}` | Чанк не производит вывода `⚠ провалился` |
| Модель возвращает сегменты, но все отсеиваются по score/duration | То же — никакого `⚠ провалился` |

Из задания: «каждый чанк: найдено 0 моментов» — это консольный вывод без строки
`⚠ R0 чанк X провалился`. Следовательно, ответ приходит, JSON валиден, но
либо `segments:[]`, либо все сегменты до порога.

**Вывод по содержанию**: с высокой вероятностью именно `segments:[]` — см.
раздел 4. Однако без явной записи сырых ответов (флаг `--debug-r0` или
инлайн-логирование в `_complete_and_parse`) это нельзя подтвердить жёстко.

## OBSERVATIONS

### Единственная причина (подтверждена кодом и содержанием)

**Комбинация двух изменений, введённых после `09ac0dd` (21 Aug):**

1. **`r0_chunk_tokens`: 4000 → 1200** — размер окна уменьшился в 3.3 раза.
   Кульминационный сегмент «И когда эти семь стадий...» теперь оказывается
   в чанке без предшествующего контекста, где «эти стадии» объяснялись.

2. **Новый хард-гейт SELF-CONTAINED OPENING** (коммит `2269699`) — корректно
   отклоняет оборванную ссылку «**эти** семь стадий» (demonstrative pronoun без
   референта внутри чанка). С прежним крупным чанком объяснение стадий было
   видно модели в том же окне → сегмент проходил.

Взаимодействие: ни одно изменение в одиночку не обязательно привело бы к нулю.
Гейт разумен; уменьшение чанков увеличивает урожай на большинстве источников
(подтверждено комментарием в конфиге). Но для этой конкретной лекции с
«кульминацией-за-горизонтом-чанка» сочетание полностью устраняет единственный
сильный сегмент.

### Альтернативные причины — исключены или неопределены

| Версия | Статус |
|--------|--------|
| Транскрипт повреждён / другой язык | ❌ Исключено: связная русская речь, 3995 слов, корректная пунктуация |
| Все чанки — провалы провайдера | ❌ Исключено: «0 моментов», не «⚠ провалился» |
| Score < 65 фильтрует кандидатов | ❌ Маловероятно: тот же контент ранее давал score 78–90 |
| Смена модели qwen3.6 → qwen3.8 | ⚠ Не подтверждена, не исключена — нет сохранённых сырых ответов |
| `max_tokens=900` обрезает JSON | ❌ При 900 помещается ≥3 сегмента; кроме того, обрезка → `⚠ невалидный JSON`, не «0 моментов» |
| Содержание принципиально не подходит | ⚠ Частично верно для ~60% (медитативные инструкции), но не для философских чанков и кульминации |
