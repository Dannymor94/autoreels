# UI-501B — synthetic soundtrack asset catalog

LOW/MEDIUM, one isolated editor slice. The existing typed TRACKS declarations are the sole source of catalog identity, format, declared rights and provenance. The synthetic editor's existing GET/PUT projection exposes those descriptors and derives permitted track choices from the same registry. The UI lists the catalog, selects by existing fixture number, and retains exact persisted Manifest/CAS semantics. No new asset lookup, file path from the client, upload, download, scan, real user media, deployment, dependency, or production renderer change. The API regression checks the actual bundled WAV bytes against the declared SHA-256, disabled demo hides catalog, and the existing browser smoke checks selection and display. Exact-head mandatory CI; no independent QA for this limited read-only metadata change. Real asset import and visual layers remain separate.
