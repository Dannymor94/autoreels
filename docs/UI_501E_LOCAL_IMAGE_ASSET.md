# UI-501E — explicit local still-image identity

First narrow still-image/B-roll prerequisite. ImageAsset is a strict, frozen, content-addressed PNG reference with declared rights and dimensions at most 4096×4096. Reuse the local asset resolver's canonical root, no-follow regular-file checks, bounded size, stable identity and streaming SHA-256; images have a separate 16 MiB limit and same-descriptor PNG signature/IHDR/CRC/dimension check. Existing WAV behavior remains unchanged. This validates identity and header only, not full PNG decoding or legal rights. Before use a trusted renderer must verify decoded frames and stage immutable bytes. No scan, upload, download, network, UI or renderer activation; no user media. Focused offline generated PNG test verifies exact hash, dimension mismatch, traversal, changed bytes, truncated file and symlink rejection. Exact-head mandatory CI; production import/hostile input decoding remains gated separately.
