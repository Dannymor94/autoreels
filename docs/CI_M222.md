# GitHub Actions: офлайн-гейт M222

Дата: 18 ноября 2026. Причина: в `main f92b4d2` нет активного workflow для проверки новых PR; одних текстовых отчётов недостаточно.

## Что проверяем

`.github/workflows/offline-smoke.yml` автоматически запускается на PR в `main` и после push в `main`. Выполняется Python 3.13 и пять существующих тестовых файлов для ядра, конфига и отбора:

- `tests/test_autocut.py`
- `tests/test_select_validate.py`
- `tests/test_config.py`
- `tests/test_models.py`
- `tests/test_models_m116.py`

Никакие API-ключи или секреты в job не передаются. Для тестового шага задан закрытый прокси на localhost:9 и `ARL_LLM_CACHE=replay`: новые сетевые обращения к моделям не должны проходить. Workflow выполняется с правами `contents: read`. Источники/видео не отправляются в облако; на GitHub живут только закоммиченные тестовые фикстуры.

## Чего этот гейт не обещает

Это **smoke-гейт, не полный pytest** и не A/B качества видео. На исходном `f92b4d2` отдельный baseline без ключа завершился `2697 passed / 29 failed / 24 skipped / 9 deselected`; часть падений связана с отсутствием опциональных библиотек, настроек тестовой среды и незакоммиченной фикстуры. Список и оригинальный лог доступны в ветке `handoff`, `handoff/m222/`.

Нельзя «лечить» CI, подставляя реальный или фиктивный API-ключ ради обхода отсутствующего окружения. Расширять полный CI можно лишь после фиксации воспроизводимого, сетево-изолированного окружения и проверки baseline failure-set на нём. Нельзя считать успешный smoke доказательством исправления 12 находок `autocut.py`.
