# UI-501M — explicit local synthetic asset library

MEDIUM, opt-in trusted local function only. A dedicated canonical directory stores content-addressed WAV/PNG/MP4 bytes and typed provenance records. The caller supplies one explicit selected file and an exact typed descriptor; no scan of user folders, HTTP path, browser upload, external network or real media. Accept synthetic rights only. Bounded same-descriptor copy, SHA-256, existing resolver and PNG header checks; publish complete files by exclusive hard link, never replace an existing object or record. Identical import is idempotent by descriptor; conflicting metadata fails; interrupted bytes-only import is invisible until registration. Catalog reads validate registered identities and never infer rights or full media validity. Actual codec/decode validation stays in trusted render path. Dedicated directory and local OS are trusted; this is not multi-tenant hostile upload handling. Directory fsync crash durability and a large-catalog indexing strategy are outside this pilot. Future actual import requires review and owner media GO. Focused offline test covers generated WAV/PNG, duplicate, changed bytes, conflicting rights/metadata, symlink, invalid dimensions and interrupted registration. No dependency or activation. Exact-head CI.
