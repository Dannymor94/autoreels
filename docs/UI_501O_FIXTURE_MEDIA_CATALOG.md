# UI-501O — bundled media catalog in editor

MEDIUM, synthetic only. One fixed visual descriptor registry feeds the existing typed graphic planner and read-only catalog projection. The UI lists bundled PNG, MP4 and WAV assets; choosing a visual asset explicitly replaces the current stack, choosing audio preserves compatible edits. Existing CAS commit and provenance metadata reused. Trusted offline registration seeds the local asset library with the four exact bundled generated files; checks are idempotent and verify content. No browser upload, arbitrary media path, user files, discovery, network, deployment or new HTTP endpoint. This is the fixture catalog, not a production/user asset picker. Focused API, browser selection, actual bundled-byte and local-library tests. Exact-head CI.
