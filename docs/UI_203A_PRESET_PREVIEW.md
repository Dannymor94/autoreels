# UI-203A — configured presets and independent override preview

Read-only configuration preview, using existing CLI loaders and local overlay through pipeline_gateway. The real config stays unchanged. GET /api/preset-preview returns only known duration presets and seven explicit flags. PUT computes a preview with strict typed global/project/clip layers and exact allowlisted base_revision. Omitted/null inherits; explicit false wins. Priority clip > project > global > configured base. Unsupported preset, missing/invalid/unsafe config or stale projection fails closed. No client path, shell or arbitrary YAML. No runtime execution, file mutation, project or review changes. The revision is only a fingerprint of exposed settings, not the full effective job hash.

Mappings: duration_preset -> R0 selection preset (not autocut target length); hook_rescue -> autocut.hook_clauses_autocut (proposal generation only); filler_word_cut -> existing technical filler candidate flag (not a general pause remover); zoom -> render.zoom.enabled; loudnorm/denoise -> audio_processing flags; two_shot and two_shot_auto -> render flags. Dependent automatic switching requested but inactive when two_shot is off; never silently enable parent. Other conditions (manual review markers, render profile, device capabilities, actual execution path) remain adapter responsibility. No claim that these flags apply identically to all clip kinds. Changes conservatively invalidate selection/plan/render for a future run only; never erase accepted edits or automatically trigger processing. This slice deliberately does not implement persisted per-project/per-clip preferences before stable IDs/revisions (UI-301), full immutable job configuration, separate acceptance/output controls for existing edits, or new algorithms. UI labels all layers as temporary examples. Remaining modules added only with actual semantics/adapter parity.

QA: real config+overlay, strict false and inheritance, no-change parity, stale rejection, dependency, invalidation, no writes/manual loss, private boundary and browser preview. No separate independent audit for this preview-only slice.
