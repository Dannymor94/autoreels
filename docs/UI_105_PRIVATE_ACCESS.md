# UI-105 — private access (HIGH)

Owner selected A in dev_4 chat; issue #41. This PR implements the application boundary and synthetic acceptance, **not network installation or live deployment**. Tailscale Serve (never Funnel) is the candidate private HTTPS reverse proxy. Official references: https://tailscale.com/docs/features/tailscale-serve and https://tailscale.com/docs/reference/tailscale-cli/serve. Existing Xray outbound routing and SSH remain untouched.

## Application boundary
- Launcher always binds 127.0.0.1, disables forwarded-header trust. Local mode retains existing routes, validates loopback Host and rejects foreign Origin; Vite 5173 local development permitted. Supported production startup is the launcher, not arbitrary public uvicorn.
- Private mode explicitly requires exact HTTPS origin and SHA-256 digest file (0600 or stricter, never in repository). Native browser HTTP Basic prompt: user owner, random high-entropy password (at least 32 random bytes). No password in URL, CLI arguments, JS or storage; no login database, no multi-user. Browser may retain HTTP auth credentials for its session; change digest/restart to revoke; close private browser session after use. This design does not rely on Tailscale identity headers. SHA-256 is for random generated secret, not a human password.
- Every HTTP request (including assets, docs, media, Range, thumbnails) must pass actual loopback socket peer, exact Host, owner credentials and origin rules; no forwarded identity or IP trust. Writes require exact Origin and JSON, bounded request body; cross-site requests denied. WebSockets disabled. No public login bypass. Private responses no-store/private, frame protection, CSP; private health redacts root. Access log disabled in private launcher. No service worker; HTTPS uses sessionStorage for browser resume/preferences (no secrets).
- Path guard rejects symlinked root descendants/aliases and non-files for media, restricts clip/variant syntax. Metadata, manifests, thumbnail cache and review storage/SQLite sidecars checked. Trusted local OS/processes and files; no claim of adversarial local filesystem race protection. Remote user cannot supply arbitrary filesystem paths. Existing review SHA and pair semantics unchanged.
- Single byte Range only in private mode, bounded request sizes and concurrency; no new renderer, external provider, new runtime package or export authorization. Native Basic assumes TLS at verified private proxy. Rate limiting for untrusted public internet is not a substitute for private network; public exposure is forbidden.

## Deployment — separate owner GO after security review
Do not run commands on owner machines in this PR. Use an isolated synthetic root first. Inventory current tailnet, OS/client compatibility, access policies and existing Serve/Funnel configuration. Confirm owner-only access policy; no Funnel, no router port forwarding, no public proxy. Verify exact HTTPS origin, upstream loopback and preserved Host. Provision secret locally via a secure terminal/password manager, store only digest in permission-restricted file outside repository; do not paste secret into chat, GitHub or logs. Launch with:
python -m autoreels.orchestr --root <isolated-root> --private-origin https://<verified-private-host> --owner-digest-file <local-digest-file> --no-browser
Candidate Serve CLI is documented at the links above; do not activate before inspecting existing config and owner approval. Verify HTTPS certificate, owner device access, denial from non-tailnet device, no Funnel/public reachability, actual range/playback and owner ability to revoke. Stop/rollback by disabling only the newly created Serve route, stopping the private launcher and reverting to localhost; do not reset existing unrelated network settings. Real media requires explicit MEDIA GO. No actual network feasibility, mobile Safari, physical phone or production performance claim.

## Minimum acceptance
Targeted API test: anonymous/forged peer/host/origin denied across reads, media and writes; owner review, comparison and Range; stale checks inherited; malformed/oversize requests; symlinks and sidecar guard; localhost compatibility. One synthetic browser using real app on loopback HTTPS with temporary self-signed certificate, native browser credentials, authorized reads/writes/range (not actual Serve transport). Existing CI/build regression. One independent HIGH security audit of the changed boundary before merge; no repeated whole-project audit. Deployment is separate authorization.
