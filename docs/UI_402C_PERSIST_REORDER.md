# UI-402C — synthetic persisted timeline reorder

Extends the existing isolated synthetic cut project and immutable Manifest revision store; natural-order candidates retain their historical bytes, SHA and legacy operation payload. The server enumerates only validated finite fixture permutations. The optional `order` is supplied only for nonchronological permutations, with positive unique disjoint IDs; a candidate digest and exact base CAS still bind the commit. No migration or second authority. Existing contiguous cut limitation remains. Reordering preserves the current cut; when changing a reordered cut, retained order stays and newly restored sentences append in source order. The UI offers pointer handles and accessible arrow controls; seeking and preview follow an explicit output window index. Restore resets both cuts and ordering; no arbitrary undo/redo stack in this slice. API and browser regression coverage plus real synthetic FFmpeg tone order acceptance added. CI evidence required before merge. No real footage, live deployment, production edits, mobile-native rendering or new dependency.
