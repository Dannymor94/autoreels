# Спецификация готового рилса (ручной путь) — v1.1

Утверждается владельцем один раз. Пока идёт пилот, правила не меняются; новые пожелания по стилю записываются в «Список на v2» внизу и вливаются только после приёмки пилота.

Область: клипы с `selection_source = human` (разметка владельца или ассистента). Автоматический путь живёт по своим правилам и сюда не относится.

## 1. Что звучит

1. Клип = предложения из разметки (`s:`…`e:` минус `x:`), в порядке разметки (или в порядке тактов `>`). Нумерация = нумерация выгрузки для разметки (склейки `+` сквозные; незаконченное последнее предложение блока сливается с первым следующего).
2. Первое слово клипа = первое слово первого предложения. Последнее слово = последнее слово последнего предложения. Ни одного слова из соседних предложений.
3. Галлюцинации Whisper («Субтитры создавал DimaTorzok» и т. п.) вычищаются до нумерации и в клип не попадают.
4. Каждый шов внутри клипа (вырез `x:`, перестановка) режется в тишине между словами по карте речи; если тишины нет — на границе слов. Никогда внутри слова. Если по карте речи два соседних слова налезают друг на друга (Whisper растянул слово на соседнее), граница берётся по энергетической тишине между ними (дорожка громкости карты речи): ближайшая к месту наложения тишина, не дальше 0.1 с от него.
5. Если выброшенное `x:` предложение по времени накладывается на соседей (дубль Whisper) и тишины для шва нет — кусок играет насквозь; в плане клипа печатается предупреждение.
6. Чистка слов-паразитов внутри предложений в v1 выключена.

## 2. Крючок (холодный старт, `h:N`)

1. Предложение N играет в самом начале клипа.
2. Повтор в теле: если N стоит во второй половине тела клипа — звучит ещё раз на своём месте (зритель узнаёт обещанное). Если в первой половине — из тела убирается (иначе «крючок и сразу та же фраза»).
3. `h:N!` — повторять всегда, `h:N-` — никогда.

## 3. План кадра (общий / крупный)

Одно простое правило, без автоматического ритма и без «сглаживающих» проходов:

1. Крючок — крупный.
2. Тело начинается общим планом.
3. На каждом шве (вырез `x:`, перестановка, переход крючок → тело) план меняется на противоположный предыдущему.
4. Предложение с `c:` — крупное; после него план возвращается к плану своего куска.
5. Больше ничего. Короткий кусок не «исправляется» кодом — он виден в плане клипа, и решение принимается разметкой.

## 4. Конец клипа

1. Конец = слышимый конец последнего слова (карта речи) + **0.30 с**, но не позже начала следующей речи − 0.06 с.
2. Пауза после последнего слова: **от 0 до 0.30 с** (меньше нуля = слово обрезано = ошибка). Если следующая речь начинается почти сразу («нет места») — клип кончается ровно на конце слова, пауза 0; в плане печатается предупреждение.
3. Быстрое затухание: картинка в чёрное за **0.25 с**, последний кадр чёрный. Звук в ноль за время паузы после слова, но не дольше 0.25 с и не короче 0.04 с — затухание звука не начинается раньше конца последнего слова (кроме случая «нет места»: тогда 0.04 с).
4. Без стоп-кадра, без искусственного хвоста.

## 5. Файл

H.264 High, yuv420p, постоянная частота кадров = номинальная частота исходника, 1080×1920, AAC-LC 48 кГц 192 кбит/с, `faststart`, обе дорожки начинаются с 0, звук с первой секунды.

## 6. Субтитры

Совпадают со звучащими словами (п. 1). Ключевые слова `k:` — жёлтым, только в своём предложении. Заголовок `t:` — плашкой, не перекрывает субтитры.

## 7. Как проверяется «готово»

1. **План совпадает с эталоном** (`benchmarks/golden/<source>_plan.yaml`): окна, порядок предложений, крючок и его повтор, порядок планов с предложениями, первое/последнее предложение. Эталон рассчитывается независимо от кода рендера.
2. **Файл совпадает с планом** (`verify_gate`): сыгранные окна, планы по кадрам, последнее слово, пауза 0…0.30 с, затухание 0.25 с, последний кадр чёрный, нет чужой речи, формат п. 5.
3. **Владелец смотрит один раз** и говорит «ок» или что не так.
4. Если одно и то же место ломается третий раз — остановиться и упростить, а не латать.

## 8. Где это в коде

`src/autoreels/cloud/plan.py` — одна чистая функция `build_manual_plan`: окна, планы, конец, субтитры. Включается `manual_plan: true` в `config/r0.yaml`. При `arl blocks --apply` план каждого клипа печатается **до** рендера; эталон — `benchmarks/golden/img6848_plan.yaml`, тест — `tests/test_manual_plan.py`.

## Список на v2
- Чистка слов-паразитов внутри предложений (рез внутри предложения).
- Короткий крупный план (< 2.5 с) — решать разметкой или правилом.
- Пока не поддержано планом (apply честно отказывает): `h:N`, где N после последнего звучащего предложения; такты `>` не по порядку исходника.
