# REPORT M175

## Шаг 1: причины отказа общего черновика (why.txt)

Два независимых типа ошибок:

### Тип A — `label used twice` (дублирование метки M в combined draft)

| источник | файл | строки |
|---|---|---|
| disko_beach_p3 | `*_auto_all_m174.txt` | M1 (line 61), M2 (line 73) |
| day_yoga_p2 | `*_auto_all_m174.txt` | M1 (line 80) |

Причина: при сборке combined draft (`arl auto`) одна и та же метка Mnn попала в файл дважды. `--apply` отказывает при первом дубле → rc=1 → auto берёт только черновик сборок.

### Тип B — `no room after last word` (клип кончается вплотную к следующей речи)

| источник | клипы | последнее слово |
|---|---|---|
| disko_beach_p1 | r01 | «становится.» (next speech 211.567) |
| disko_beach_p3 | 3 клипа | «человечек.», «посмотрим.», «колесе.» |
| day_yoga_p2 | 6 клипов | «секунды.», «секунд.», «ребята.», «присутствует.», «предназначение.», «обычно.» |
| prew_isaev_anna | r01, r02, r04 | «реализовался.», «готова.», «месте.» |
| prew_isaev_danny | r02 | «регулярно.» |

Ошибка присутствует и в combined draft, и в label-only draft (`*_auto.txt`) → коренная причина в определении конца клипа: следующая речь начинается раньше, чем успевает закончиться требуемый tail-silence. Клипы с этой ошибкой отклоняются при `--apply`.

### Почему 86 → 60 клипов (итог)

Три причины вместе:
1. **`label used twice`** (тип A): combined draft отклоняется целиком → берётся только черновик сборок
2. **`no room`** (тип B): отдельные клипы отклоняются и из combined draft, и из label-only draft
3. **Новые сборки = другие клипы**: `arl auto --gate m174` запускался заново; сценарист дал другой набор сборок, чем был в m157 (prew_isaev_anna: 9 вместо 20; prew_isaev_danny: 11 вместо 26). Это нормально — каждый прогон автоматики независим.

Полный вывод — `handoff/m175/why.txt`.
