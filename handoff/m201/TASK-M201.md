# TASK M201 (окно MAIN, Mac): платная модель молчит с m197 — причина; текст ошибки в логах; куда ушёл «Алгоритм или эмпатия»

Файлы — ветка `handoff`, папка `handoff/m201/`:
- `TASK-M201.md`;
- `m201-provider-errors.patch` — код и тесты; патч написан и прогнан ассистентом;
- `ping_claude.py` — один короткий запрос к sonnet и haiku через код проекта, печатает ответ или ошибку;
- `gate_posts.py` — сколько клипов гейта без поста (только чтение).

Около 15 минут, без рендера, без `arl auto`. Отчёт — только на русском.

## Зачем
Ассистент разобрал логи m197 и m200 (`handoff/m197/auto.txt`, `handoff/m200/auto.txt`).

1. **С m197 платная модель не отвечает ни на один новый запрос.** Каждый вызов заголовка, ключевых слов, стыков, крючка и описания поста падает:
   - m197 (2 источника): заголовок 24, ключевые слова 24, описание 9, стыки 5 — все `модель не ответила (ProviderError)`;
   - m200 (все 7 источников): заголовок 63, ключевые слова 63, стыки 16, крючок 5.

   Отвечает только кэш (сценарист, часть судей), поэтому прогон выглядел как «из кэша, $0». Код печатает только имя класса ошибки, а строка расхода Claude при нуле удачных запросов не печатается совсем. Так поломка прожила два дня незаметно. Последствия: у клипов без кэша нет `k:`, плашка — заголовок сценариста без доработки моделью, стыки не проверены, а у части клипов m196 (пересобраны в m197) нет поста — `arl describe` не пишет файл, когда модель молчит.
2. **«Алгоритм или эмпатия» (prew_isaev_anna, `20.9-10 21.1-5 22.2-3`) ушёл из m200 не по `start_morph`.** Счёт сценариста: принято 13 = 6 сборок + 6 «не прошли проверку» + **1 «похожи на принятые»** (`too_close`, `max_shared: 0`). В консоль этот раздел идёт только числом, поэтому строки `✗` у клипа нет. Слепые судьи (m192b, X01) этот клип ценили: оба «fix», «мысль хорошая, начать с „алгоритм полезен, но…“». В отчёте M200 написано, что `answer_start` начал его со следующей фразы ✓, но `export_diff` показывает «только m200: 0» — значит, дальше клип ушёл. Часть 3 показывает, с кем он совпал.

Выход клипов и разметки не меняется: правятся только строки лога и строка расхода. Ассистент прогнал весь набор: 2632 прошли (было 2627 + 5). 7 упавших требуют ffmpeg, praat или данных `data/runs/` — без патча падают те же 7.
