### P0-2 Trace path is not race-safe

`cmd_autocut` checks `Path.resolve()` and later uses `os.open(path, O_TRUNC | O_NOFOLLOW)` (`__main__.py` near 9327–9345). `O_NOFOLLOW` covers only the last component, not parent directory symlinks. A synthetic temp-directory repro changed the parent to a symlink between validation and open and demonstrated a write through that parent into a fake protected repository file. Separate repro overwrote an existing regular external file because of `O_TRUNC`. On Python 3.12 a symlink loop can make `Path.resolve()` raise `RuntimeError`, uncaught by the `except OSError` branch. Implement a path and write boundary that is atomic for parent components, refuses existing targets, and silently fails closed on unsafe paths without disturbing legacy CLI output. Include adversarial test oracles, not only a final-component symlink test. Do not use real repository files as destructive targets.
